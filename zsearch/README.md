# ⌕ zsearch

### 全文搜索

**把记得的词变成能重新找到的资料位置。**

> 状态：已有实现 · 公开快照：2026-09-10
>
> 本目录是模块介绍占位，不包含私有源码或业务内容。

## 在系统中的位置

| 输入 | 输出 |
|---|---|
| 私有文稿与检索词 | 全文检索结果及来源位置 |

## 模块职责

- 基于 Meilisearch 建立全文索引。
- 按关键词查找资料段落。
- 提供来源信息，支持回看上下文。

## 公开范围

公开介绍检索结构，不展示真实课程查询结果或索引库。
