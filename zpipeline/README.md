# ⇄ zpipeline

### 资料同步

**把重复的资料获取和文稿整理变成可追踪的流程。**

> 状态：已有实现 · 公开快照：2026-09-10
>
> 本目录是模块介绍占位，不包含私有源码或业务内容。

## 在系统中的位置

| 输入 | 输出 |
|---|---|
| 私有资料来源 | 文稿、导出产物与同步状态 |

## 模块职责

- 扫描资料来源并处理文稿导出。
- 连接文稿组织与后续索引。
- 保留同步状态，支持持续增量维护。
