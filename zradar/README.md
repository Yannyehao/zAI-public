# ◈ zradar

### 选股与候选跟踪

**把盘后行情变成可复核的观察清单，保留候选后续变化。**

> 状态：运行维护与能力迭代 · 公开快照：2026-09-10
>
> 本目录是模块介绍占位，不包含私有源码或业务内容。

## 在系统中的位置

| 输入 | 输出 |
|---|---|
| 行情、版本化规则与市场背景 | 候选卡、复盘页面、终端列表与状态归档 |

## 模块职责

- 盘后扫描与数据新鲜度检查。
- 候选分析字段与连续状态跟踪。
- 规则版本、案例评估、对照与回滚入口。

## 公开范围

已有 A 股与美股工作流；市场和图形判断仍在完善。具体规则、参数及真实交易信号不公开。
