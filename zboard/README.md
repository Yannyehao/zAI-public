# ▦ zboard

### 项目进度与证据

**把已有任务与开发记录转成项目看板，让进度有出处。**

> 状态：已有实现，持续迭代 · 公开快照：2026-09-10
>
> 本目录是模块介绍占位，不包含私有源码或业务内容。

## 在系统中的位置

| 输入 | 输出 |
|---|---|
| 任务记录、开发日志与项目分类 | 项目看板、结构化汇总与指标证据 |

## 模块职责

- 整理 Projects、Epics 与 Sprints 层级。
- 将任务与变更依据连接起来。
- 输出看板和带证据、限定词的工程指标。

## 公开范围

公开模块定位；真实任务台账、内部项目和指标数值保留在私有空间。本次核对文档，未重跑看板生成。
