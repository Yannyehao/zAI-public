# 公开内容边界

## 本仓库公开什么

个人项目叙述、模块职责、系统架构、交易辅助的信息组织方式、工程方法和重新撰写的经验总结。

合成示例可以包含虚构标识、数字和文案，但需要在示例开头说明来源与用途；不将其包装成系统运行证据。

## 保留在私有空间的内容

- 录播、字幕、逐字稿、课程画面、知识提炼及其可还原的详细内容。
- 具体交易判据、参数、策略源码及私有提示词。
- 账户、凭证、个人记录、生产数据和内部页面链接。

提到 z 哥，是说明个人学习背景；不表示授权、合作或背书。本仓库不代表他发言。

## 更新方式

公开内容逐篇重新整理，不自动同步私有文件、提交历史或内部日志。每次检查可见文件、Git 历史、链接与图示，确认能力状态和示例标记一致。

当前没有提供软件开源许可证，也不对第三方素材授予任何使用权。
