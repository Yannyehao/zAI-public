# 正在做什么，未来是什么

更新于 2026-09-10。此页区分私有系统的方向与公开档案的交付，不承诺尚未排期的发布日期。

## 系统持续完善的方向

- **图形判断与评估：** 保留版本和人工案例反馈，逐步明确能判断与不能判断的边界。
- **市场与板块背景：** 改进上下文组织，帮助解释候选所处环境。
- **学习工作流：** 持续完善录播处理、人工审阅和产物验收。
- **运行可靠性：** 补齐较弱的产物检查，减少需要人工排障的重复问题。

这些是方向概览，具体优先级会随实际验证调整。
