# ▷ zclip

### 录播学习工作流

**把长录播整理成可导航、可审阅的个人学习产物。**

> 状态：已有流程，持续完善 · 公开快照：2026-09-10
>
> 本目录是模块介绍占位，不包含私有源码或业务内容。

## 在系统中的位置

| 输入 | 输出 |
|---|---|
| 私有录播与人工选材 | 学习笔记、剪辑产物与验收记录 |

## 模块职责

- 按阶段组织转写、定位、剪辑与图文处理。
- 剪辑前与成片后保留人工审阅。
- 检查阶段产物，支持独立重跑。

## 公开范围

这是人在环的学习工作流，不是全自动出片。源视频、课程笔记及剪辑成果不在本目录公开。
