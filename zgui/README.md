# ▣ zgui

### 健康与诊断

**把分散的任务状态聚合成一个可读的运维入口。**

> 状态：维护中 · 公开快照：2026-09-10
>
> 本目录是模块介绍占位，不包含私有源码或业务内容。

## 在系统中的位置

| 输入 | 输出 |
|---|---|
| 任务状态、成功标记与诊断信息 | 本地健康面板与诊断结果 |

## 模块职责

- FastAPI 页面聚合现有状态信道。
- 按模块与依赖查看异常。
- 配合独立恢复流程与健康通知。

## 公开范围

面板负责观察；自动恢复是独立流程。不要把面板的存在理解为所有异常都能自动修复。
