# ≡ ztxt

### 文本镜像

**为需要纯文本的索引和工具提供文稿镜像。**

> 状态：已有实现 · 公开快照：2026-09-10
>
> 本目录是模块介绍占位，不包含私有源码或业务内容。

## 在系统中的位置

| 输入 | 输出 |
|---|---|
| 文稿集合 | 对应的纯文本镜像 |

## 模块职责

- 提供适合文本工具消费的形式。
- 保持与文稿来源的对应关系。
- 为检索与后续处理提供输入。

## 公开范围

只有公开介绍；不存在可供下载的录播文本。
