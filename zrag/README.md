# ◎ zrag

### 语义检索与问答

**用语义检索找回相关资料，在来源上下文中组织回答。**

> 状态：已有实现 · 公开快照：2026-09-10
>
> 本目录是模块介绍占位，不包含私有源码或业务内容。

## 在系统中的位置

| 输入 | 输出 |
|---|---|
| 私有文稿、向量索引与问题 | 回答与来源列表 |

## 模块职责

- BGE-M3 本地向量化与 Chroma 检索。
- 向问答模型传入检索到的来源上下文。
- 输出回答与来源列表供人工复核。

## 公开范围

引用存在不保证回答正确。私有提示词、向量库和真实回答不发布。
