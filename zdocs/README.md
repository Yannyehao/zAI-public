# ▤ zdocs

### 文稿组织

**给个人学习文稿一个稳定的组织入口。**

> 状态：已有实现 · 公开快照：2026-09-10
>
> 本目录是模块介绍占位，不包含私有源码或业务内容。

## 在系统中的位置

| 输入 | 输出 |
|---|---|
| 处理后的私有文稿 | 按时间组织的文稿集合 |

## 模块职责

- 维护文稿的组织结构。
- 作为文本镜像和索引的上游。
- 让资料能够按来源定位。

## 公开范围

公开目录不放实际文稿、节选或课程内容。
